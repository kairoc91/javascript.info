# JavaScript.info — Estudos e Prática

Repositório dedicado ao registro da minha trilha de estudos em JavaScript moderno, contendo anotações, exemplos de código e resolução de exercícios baseados no tutorial oficial [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info/).

---

## 🎯 Objetivo

- Consolidar os fundamentos da linguagem JavaScript (ES6+).
- Resolver os exercícios propostos a cada capítulo com código limpo e boas práticas.
- Construir uma base sólida tanto para desenvolvimento de software quanto para resolução de problemas em tempo de execução (Node.js e Browser).

---

## 🗂️ Estrutura do Repositório

A organização dos diretórios segue a ordem curricular do [javascript.info](https://javascript.info/):

```text
.
├── 01-js/                      # Parte 1: A Linguagem JavaScript
│   ├── 01-getting-started/     # Introdução e configuração do ambiente
│   ├── 02-first-steps/         # Fundamentos: tipos, variáveis, operadores
│   │   └── 01-hello-world/
│   ├── ...
├── 02-browser/                 # Parte 2: Navegador, DOM, Eventos e Interfaces (a adicionar)
└── 03-advanced/                # Parte 3: Artigos adicionais e tópicos avançados (a adicionar)
```

Dentro de cada diretório de tópico você encontrará:
- Exemplos comentados de conceitos-chave.
- Resoluções dos exercícios propostos no tutorial.
- Scripts executáveis via Node.js ou páginas HTML simples para testes no navegador.

---

## 🚀 Como Executar

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado (recomendado v18+ ou versão LTS atual).

### Executando exemplos em Node.js
Navegue até o diretório do exercício desejado e execute via terminal:

```bash
node caminho/para/o/arquivo.js
```

### Executando exemplos com HTML / Navegador
Abra o arquivo `.html` diretamente no seu navegador de preferência ou utilize uma extensão como o *Live Server* (VS Code).
